# tmux 設定 (`.tmux.conf`)

このリポジトリは，tmux を快適に使うためのカスタム設定ファイルです．

## 必要なパッケージ

クリップボード連携のためのコマンドを OS ごとに用意します．

### Linux (`xsel`)

| ディストリビューション | インストールコマンド |
|---|---|
| Ubuntu / Debian | `sudo apt install xsel` |
| Fedora / RHEL 系 | `sudo dnf install xsel` |
| Arch Linux | `sudo pacman -S xsel` |

インストール後，以下のコマンドで導入を確認できます．

```bash
which xsel
xsel --version
```

> **Note:** `xsel` は X11 のクリップボードを扱うため，GUI セッション（X11 / XWayland）が起動している必要があります．SSH 接続先のヘッドレス環境では動作しません．その場合は本 README の「トラブルシューティング」を参照してください．

### macOS (`pbcopy`)

`pbcopy` は macOS に標準搭載されているコマンドのため，追加インストールは不要です．以下で存在を確認できます．

```bash
which pbcopy
# => /usr/bin/pbcopy
```

万が一見つからない場合は，macOS のシステムが破損している可能性があるためシステム復旧を検討してください．Homebrew 等でのインストールは不要です．

## インストール

```bash
cp .tmux.conf ~/.tmux.conf
```
上記のコマンドで設定が反映されない場合は，以下のコマンドを実行してください．
```bash
tmux source-file ~/.tmux.conf
```

## 基本設定

| 設定項目 | 値 |
|---|---|
| Prefix キー | `Ctrl + o` |
| キーモード | vi モード |
| ヒストリ上限 | 100,000 行 |
| マウス操作 | 有効 |
| 256 色対応 | 有効 |

> **Note:** デフォルトの Prefix (`Ctrl + b`) を `Ctrl + o` に変更しています．
> 以降のキーバインドはすべて `Ctrl + o` に続けて入力します（`Prefix` と表記）．

---

## キーバインド一覧

### 設定リロード

| キー | 動作 |
|---|---|
| `Prefix` + `r` | `~/.tmux.conf` を再読み込みする |

---

### ウィンドウ操作

| キー | 動作 |
|---|---|
| `Prefix` + `Ctrl+c` | 新しいウィンドウを作成 |
| `Prefix` + `Ctrl+n` | 次のウィンドウへ移動 |
| `Prefix` + `Ctrl+p` | 前のウィンドウへ移動 |

---

### ペイン分割

| キー | 動作 |
|---|---|
| `Prefix` + `h` または `\|` | 縦分割（左右） |
| `Prefix` + `v` または `-` | 横分割（上下） |

---

### ペイン移動

vi キーとコントロールキー両方に対応しています．

| キー | 動作 |
|---|---|
| `Prefix` + `Ctrl+h` | 左のペインへ移動 |
| `Prefix` + `Ctrl+j` | 下のペインへ移動 |
| `Prefix` + `Ctrl+k` | 上のペインへ移動 |
| `Prefix` + `Ctrl+l` | 右のペインへ移動 |
| `Ctrl + ←` | 左のペインへ移動（Prefix 不要） |
| `Ctrl + →` | 右のペインへ移動（Prefix 不要） |
| `Ctrl + ↑` | 上のペインへ移動（Prefix 不要） |
| `Ctrl + ↓` | 下のペインへ移動（Prefix 不要） |

---

### ペインのリサイズ

`-r` フラグにより連続入力が可能です（デフォルト 5 単位）．

| キー | 動作 |
|---|---|
| `Prefix` + `Ctrl + ←` | 左に拡大 |
| `Prefix` + `Ctrl + ↓` | 下に拡大 |
| `Prefix` + `Ctrl + ↑` | 上に拡大 |
| `Prefix` + `Ctrl + →` | 右に拡大 |

---

### ペインの全画面切り替え（ズーム）

| キー | 動作 |
|---|---|
| `Prefix` + `z` | 現在のペインを全画面表示にする / 元に戻す |

> **Note:** もう一度 `Prefix + z` を押すと元のレイアウトに戻ります．これは tmux の標準機能です．

---

### ペイン同期

| キー | 動作 |
|---|---|
| `Prefix` + `a` | 全ペインへのキー入力同期をトグル |

同期がオン/オフになるとステータスバーにメッセージが表示されます．

---

### コピーモード（vi モード）

`Prefix` + `[` でコピーモードに入ります．

| キー | 動作 |
|---|---|
| `v` | 選択開始 |
| `V` | 行全体を選択 |
| `Ctrl + v` | 矩形選択の切り替え |
| `y` または `Enter` | 選択範囲をクリップボードにコピーしてモード終了 |
| `Escape` | 選択範囲を解除 |
| マウスドラッグ → 離す | 選択範囲をクリップボードにコピーしてモード終了 |

#### クリップボード連携

| OS | 使用コマンド |
|---|---|
| Linux | `xsel --clipboard` |
| macOS | `pbcopy` |

OS は `uname` により自動判定され，リロード時にステータスバーへ使用コマンドが表示されます．

---

### ペインボーダー表示

各ペインのボーダーに `tty 名` と `カレントディレクトリパス` が表示されます．

---

## ステータスバー

- 背景色: `colour238`（ダークグレー）
- 文字色: `colour255`（白）
- アクティブウィンドウ: 緑背景 (`colour2`) で強調
- Prefix 入力中: 黄背景 (`colour3`) に変化

---

## トラブルシューティング

### クリップボードにコピーされない（Linux）

`xsel` がインストールされているか確認してください．

```bash
which xsel
```

未インストールの場合は以下を実行してください．

```bash
sudo apt install xsel
```

また，SSH 接続先などの GUI を持たない環境ではクリップボード連携できません．その場合は `.tmux.conf` の `set -s set-clipboard on` への変更と，ローカル端末側での OSC52 有効化を検討してください．

### クリップボードにコピーされない（macOS）

`pbcopy` は macOS 標準コマンドのため，通常は追加設定不要です．動作しない場合は tmux をリロード（`Prefix + r`）し，ステータスバーに `using pbcopy as copy-command` と表示されることを確認してください．

### 設定が反映されない

tmux を起動したまま設定を変更した場合は，リロードしてください．

```bash
# tmux 内で
Prefix + r

# またはシェルから
tmux source-file ~/.tmux.conf
```
